# Mech

A BattleTech mercenary company management game, focused on business decisions that shape battles and battles that reshape the business.

The first milestone is a browser-based TypeScript strategy game: draft a starting lance and its MechWarriors, accept contracts, travel, deploy, apply authored mission outcomes, and manage repairs and quarterly expenses. Playable real-time combat with pausing will follow.
