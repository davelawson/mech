# Instructions for AI assistants

- **Documentation:** record game behavior and rules in the matching `docs/` file: strategy screens and campaign rules in `docs/design.md`, combat behavior in `docs/combat-design.md`, combat numbers in `docs/combat-tuning.md`, model and paperdoll details in `docs/mech-models.md`. `README.md` only gains setup steps, build/test/export commands, and new inputs in its Controls table.
- **Tests:** run `scripts/mech test` after changes. It builds, imports assets, and runs the headless test scene.
- **Terminology:** use the project terms defined in `CONTEXT.md`.
