## Tactical Layer
### Main Tactical View
- improved the mech details panel for selections
  - mouseover mech locations shows the systems in that location, colour coded by damage level
  - abbreviated systems list
    - show heatsinks as a stack
    - dont' show actuators, etc.
    - show engine, gyro, sensors, and ammo
    - show range brackets for each weapon
- add paper dolls to the quick selection buttons along the bottom of the screen
- mech animations for jumping
- Improve terrain features
- Convert all distances to meters rather than hexes.  Outlaw hexes.  1 hex = 30 meters.
- Make shooting cooler:
  - Sounds
  - Distinct graphics
    - Laser, with diff colours for diff types
    - AC, projectiles, burst fire, etc.
    - Missiles: swarms, arcing
    - Machine guns: tracers, ricochets
  - Should fire from where the weapon is on the model
  - Misses should miss the target mech
  - Hits should impact on the appropriate location
  - Explosions!
- Allow multiple commands to be queued up by holding shift.
