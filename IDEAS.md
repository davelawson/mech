# MECH GAME PROJECT OUTSTANDING IDEAS
This file serves as a repository for ideas that await implementation or further design at a later point.  This is not the plan for the next development task, but rather a wishlist of future features and a repository for issues that will require fixes.

### Briefing Interface
- While in the briefing, give access to view the battlefield in the actual 3d view, so the player can explore it and come up with ideas and strategies.  Some missions might prohibit this, and sometimes the map could be wrong.

### Hangar Interface
- Horizontally center the location names within their component panels.
- Add control for selling systems from inventory
- swapping pilot from the mech hangar view shouldn't require a confirmation
- mouse over on weapons should give weapon specifics (ie. tonnage, heat, damage, range) both in components and in storage
- buying and selling mechs
- Add a per-mech history, like the MechWarriors' service history (pilots, kills, damage taken, battles fought)
- repair at the same time as refitting.  Maybe clicking on repair armour sets armour to be repaired, but still requires 'Apply'
- manually making and undoing a change on a mech still triggers a refitting job
- allow mechs to be over/under tonnage.
  - undertonnage increases speed generated by the engine
  - over-tonnage has double impact on speed calculations

### Roster Interface
- Specialist staff.  These are people that add specific one-off bonuses.
  - Diplomatic aide: grants some bonus in contract negotiation or procurement
  - System specialist: grants some kinda bonus related to a particular family of mech systems
  - Repair specialist: makes repair cheaper or faster
  - Armour specialist: reduces damage taken until armour is breached on a location
  - Cable management specialist: reduces likelihood of suffering critical hits when structure takes damage.
  - Financial Advisor: allows unspent funds to generate a modicum of income.
  - Doctor: reduces injury recovery time, and has a chance to recover a pilot that killed in action.
  - Navigation expert: Increases the distance that can be jumped in a single day
  - Munitions expert: Shot that miss don't consume munitions
  - Laser/Ballistics/Missile specialist: somehow improves those weapons
  - Engine enthusiast: Mech move a bit faster
  - etc.
- More service history events: top damage dealer in a mission, holding their nerve while Panicked, forcing an enemy surrender, kill milestones beyond the fifth
- Name enemy MechWarriors so histories (and rivalries) can say who was killed
- add pilot abilities that help their lance
